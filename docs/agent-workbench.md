# Agent 工作台

实现：`src/components/AgentPanel.vue`、AgentTaskSpec、AgentEvidence、AgentArtifact，以及 App 的工具应用端口。

工作台展示连接状态、目标、步骤、参数、工具结果、证据、任务规格和可保存成果。支持取消、接续修改、重新取数与保存本地审计。

模型连接必须通过能力检查与工具调用探测。模型断开时，可以继续手动使用两段 ROM 任务卡，以及姿态采集、图表和普通导出。

## 两段 ROM 比较任务卡

1. 采样后打开 **AI Agent 分析 → 两段 ROM 比较任务卡**。可以先选 **暂停采集以核对范围**，固定审阅所用的会话版本。
2. 选 **手动填写**，设置关节、侧别、raw 或 filtered、统计前段、统计后段和图表范围。明确给出 15–20 秒时，选 **绝对秒区间** 并输入 15 和 20。仅当需要从采样起点或终点算起时，选 **采样开头若干秒** 或 **采样末尾若干秒**。每栏显示当前会话中的实际起止秒或具体错误。图表选 **覆盖两段** 时，随两段范围更新。
3. 已连接模型时也可选 **用当前模型草拟**，输入目标后生成待审阅参数。逐栏检查区间类型及实际起止秒，直接在卡片上纠正。草拟期间可以点 **取消草拟**，也可以点 **手动填写** 结束等待并回到表单。服务异常、超时、断开、草稿无效或会话更新时，页面保留已填值。**模型草拟审计**可单独保存请求、会话版本以及已接收的回复或失败原因。
4. 换源、重算或新增样本后，任务卡显示当前会话的展开区间并暂停确认。点 **按当前会话重新审阅** 暂停采集，核对各栏后再选 **确认并运行比较**。浏览器先读取当前会话，版本一致时才计算两段 ROM 和后段减前段的差值、应用图表并准备勾选的成果。确认瞬间版本变化会留下过期审计，可重新审阅后再确认。结果卡可查看本地证据、定位和保存完整审计。
5. 接续时选 **修改已确认参数**，例如只改右侧与后段 12–17 秒。前段、关节、口径和其他选项沿用上次确认值。核对变化列表后确认启动新运行。图表原先若选 **覆盖两段**，此例会从 0–20 秒更新为 0–17 秒。
6. 勾选 **准备比较报告** 或 **准备 CSV** 再确认。在结果成果卡分别点 **保存报告 JSON** 或 **保存 CSV**。报告统计两段，CSV 使用图表的闭区间，保留完整 354 列。换源或重算后，旧成果的定位与保存入口失效。

每次确认的审计保存输入类型、用户确认参数、实际展开区间和会话版本。引用来源标为浏览器本地工作流。

## 从自由目标发起两段 ROM 比较

1. 验证模型连接，在 **让工具完成分析目标** 输入目标并点 **执行目标**。模型声明两段 ROM 后，页面打开同一张任务卡。核对原目标、模型选择的区间类型、当前实际秒数、侧别、raw 或 filtered、独立统计、质量、图表和成果选项。
2. 在卡片上直接纠正。例如目标写的是绝对 15–20 秒，而草稿选择了采样末尾 5 秒，就切换到 **绝对秒区间** 并填 15 和 20。图表可选 **覆盖两段**，CSV 可以指定自己的导出区间。点 **确认并运行比较** 才开始比较、绘图和准备成果。
3. 接续目标仍从同一输入框发起，每轮重新确认。也可以在审阅期间点 **取消本次审阅**。等待时如果换源、重算或增加样本，页面会结束旧审阅，需要按当前会话重新提交。
4. 结果卡显示本地完成检查、来自当前工具的必需引用和具体缺项。完整审计保存原始模型声明、用户确认输入、会话版本、实际工具及引用来源。

图表完成要求视图实际应用。**已准备**表示报告或 CSV 可由句柄取得。点击 **保存报告 JSON** 会发起浏览器下载。点击 **保存 CSV** 后，页面会区分文件流写入完成和已发起浏览器下载。更换输入、重算或版本变化后，旧证据和保存入口失效。

工作台不呈现未经验证的模型数字，不执行任意脚本或任意网络 URL。协议回归通过只说明执行链路可运行，真实模型是否能正确理解和完成目标须独立检验。

检查命令与当前结论见 [项目评估](project-assessment.md)。
