# 时序可视化

实现：TimeChart、MarkerTimeline、PoseStage、`src/utils/visualization.ts`、renderer 和 export。

界面提供关节角度、速度热力、髋中心轨迹、关键点 raw/filtered X/Y 曲线及左右对比。左侧蓝色，右侧橙色，低置信或缺失数据不补造量测。

显示聚合保留端点、极值与缺失断点，不改变原始统计数据。速度热力按时间桶保留最大绝对速度；轨迹按来源比例等比例显示，X 向右、Y 向下。

标记在时间轴上按相邻时间分组，同一组仍可逐项选择。框选、截取、回看和 Agent 图表使用各自明确的范围。

PNG 报告按当前画布比例排版，区分画面时刻与统计区间，携带会话版本及参数。姿态距离仅为用户选择参考下的描述数值，不是动作评分。
