# 多轮上下文与审计

实现：`src/agent/taskContext.ts`、`src/agent/contextFeedback.ts`、`src/agent/audit.ts`。

TaskContext 当前版本为 1.1.0。上下文保留已接受任务、尚待处理的用户修改和最近反馈；后续请求不直接携带完整历史数值。

限制：最多 64 轮、8 个待处理目标、32,000 字节意图、180,000 字节单请求、12,000 字节反馈，最近错误保留 2 项。

部分修改使用 set_task_patch。未改变的字段原样继承，业务参数不从旧结果猜测。失败、取消和超时后的原始意图可继续澄清；旧数值及证据不能复用为新轮事实。

会话版本变化后保留可追溯目标，但旧引用、成果句柄和不可用区间须重新验证。完整请求、响应和工具结果存入本地审计，与发送给模型的有界上下文分开。

本次验证见 [项目评估](project-assessment.md)。
