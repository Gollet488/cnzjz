# 本地视频逐帧分析

实现：`src/video/mp4.ts`、timeline、job、protocol、offline.worker，以及 PoseStage。

格式检查和 MP4Box 容器索引在 Worker 中运行。WebCodecs 按解码顺序处理，结果按源显示时间审计。MediaPipe 在 Worker 中运行离线和摄像头推理，离线预览和推理共用同一张位图。视频和图像帧保留在浏览器内。

导入层 `src/video/prepare.ts` 根据文件内容判断格式，单视频和双视频对比共用。MP4Box 与 WebCodecs 能直接读取的文件保持原数据。其他文件由浏览器本地 FFmpeg WebAssembly 尝试直接重封装视频轨道，验证通过即可沿用原编码帧；需要兼容旧编码、转换画面或处理异常索引时再重新编码。转换资源从本站 `/ffmpeg/` 读取，纯静态部署可用。

常见容器包括 MP4/MOV/MKV/AVI/WebM/FLV/WMV/MPEG/TS/3GP/OGV/MXF 等，实际解码能力以随附 FFmpeg 核心为准。损坏、加密、无视频轨道或仍无法解码的文件会显示错误。兼容的 H.264 MP4 可分段直读，最大 2 GB。需要转换的文件上限为 500 MB，转换输出占用 WASM 内存。转换最多运行 10 分钟，可主动取消。换源、替换文件或卸载组件会终止转换 Worker 并释放内存。

H.264 MP4/MOV 支持直接分析。HEVC MP4/MOV 在浏览器支持播放且首帧试解通过时保留原编码。转换选取第一条视频轨道并去掉音频和字幕。直接重封装保留编码帧。重新编码时应用旋转和像素比例，横向画面上限为 1920×1080，纵向画面上限为 1080×1920，并保留可变帧率间隔。转换后验证 MP4 索引和 WebCodecs 支持。完整性核对和时间轴以转换后视频为准。会话、工具证据与 CSV 的 `acquisition_mode` 使用 `webcodecs-transcoded` 标记转换路径。

上传后可在「视频片段」中逐帧查看，在时间轴或秒数输入框设置起止点，也可按 0.25×–3× 预览。起止点吸附到呈现帧，两端均纳入分析。预览速度只控制播放，角度、速度和 CSV 使用原视频或转换后视频的时间轴。片段任务从邻近关键帧开始解码，只提交并核对所选区间内的帧，采集模式带 `-clip`。

分析范围超过 18,000 帧时，按呈现时间均匀选取最接近各采样时刻的源帧，最多保留 18,000 帧，包含首尾。解码仍核对分析范围的完整呈现序列。进度显示已处理帧数与检测到人体的帧数。会话与 CSV 使用 `-sampled` 模式后缀和 `sampled` 完成状态，帧间快速动作可能漏采。

部分人体入镜时，保留仍有可信观测的点。人体形态检查按源画面宽高比计算投影长度，出框或坐标异常的点记为不可用。关节所需各点均达到置信阈值，且原始投影的两段均足够长时才计算角度。人体丢失或近期可见的关节点变弱时，对同一帧使用独立模型补检，视频模型继续保持追踪状态。离线分析可对画面中较小的人体做局部补检，补检结果需与当前人体的可见关键点匹配。仍缺失的测量保留时间戳，角度和速度留空。

暂停时保持背压，恢复不重复写帧。取消、重置和换源后关闭资源并拒绝迟到写入。会话拒绝帧时解码任务终止，不把已丢失样本计为完成。

采集元数据记录预期/已处理帧数、状态、编码、旋转和时间偏移，随工具证据及 CSV 导出。合成素材来源由用户明确标记。

必要回归素材位于 tests/fixtures，含固定哈希和独立时间戳 oracle；这些素材不证明真实运动视频精度。当前验证见 [项目评估](project-assessment.md)。

## 双视频对比

对比按参考视频的对齐后时间分配采样区间，默认每 0.1 s 一格；最长保留 18,000 个采样格，超长视频相应拉长间隔。支持视频帧回调的浏览器优先使用各路呈现帧的媒体时间，否则使用播放时钟。两路样本都落在重叠区间内且对齐后时间差不超过 0.1 s 才配对；每格最多一对。播放掉帧、推理耗时和重新对齐都可能留下空格。

两路分别报告检测通过的样本、可信关键点数与关节有效值。关节差值为待测减参考；平均绝对差和峰值只使用两路都有角度的样本。区间平均几何距离只使用两路几何距离可计算的采样对。数据为二维投影测量，空缺保持为空。

对比 CSV 每个计划采样格一行。`paired` 表示成功配对，即使画面中无人也保留两路时间；`missed` 表示已越过且没有配对的格；`not_reached` 表示导出时分析尚未确认到达该格。文件包含两路时间及其来源、配对偏差、检测状态、可信点数、原始与滤波角度、角度差和归一化几何距离，以及源视频、对齐起点和分析参数。转换过的视频使用转换后时间轴。切换页面、换源或修改测量参数会清除本次对比。
