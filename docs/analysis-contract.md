# 分析契约

依据：`src/analysis/session.ts`、`src/analysis/tools.ts`、`src/utils/poseMath.ts`。

- 会话引用由 sessionId 和 revision 组成。追加、重算、采集元数据或素材来源改变后，旧引用失效；重置生成新 sessionId。
- 参数包含置信阈值、滤波窗口、来源宽高比和 metricVersion；当前指标版本为 2.1。历史 2.0 指标快照保留原版本。
- 输入为 33 个有限坐标及 visibility，或无检测的空数组。源时间必须有限、非负且递增。
- raw 坐标独立保留；filtered 使用可配置均值窗口。缺失或低置信数据中断连续滤波与导数。
- 角度计算修正来源比例。组成角度的任一投影线段短于源画面高度的 0.5% 时，视为方向不可可靠辨识；原始角度无效时，滤波角度也留空，独立关节仍可计算。该阈值是几何保护规则，未经人体真值标定。速度采用实际源时间差。脊柱是单中线量，其余关节使用左右通道。
- ROM 为区间最大角度减最小角度。区间边界不借用区间外速度，单个有效样本不能构成活动范围。
- Web 关节活动幅度表同时展示各侧/中线有效角度样本数和覆盖率，分母为当前图表区间与片段交集中的全部已采样帧（包括未检出帧）；空区间覆盖率为空。覆盖率不是源视频覆盖率、置信度或人体测量准确率；少量样本仍可能产生不稳定的 ROM。
- 髋中心是身体中心的二维近似。坐标总体方差不等同动作质量，主动运动、噪声与视角都会改变它。
- 可比较时差值为第二段减第一段。区间与采样缺口重叠或其他可比条件不满足时，保留每段独立统计、留空差值并说明原因，报告不生成变化方向。
- `get_quality_summary` 的可选 `selection={joint,channels,basis}` 使用与角度查询相同的有效性口径。各侧分别返回有效/无效样本及帧覆盖率；无效分为整帧未检出和检出但选中角度不可用（可能置信不足或几何退化），不根据这些计数猜测遮挡原因。全点可靠率独立保留，不能替代局部可用性。
- 采样连续性在写入帧时判定：阈值为之前最多 9 个相邻采样间隔的中位数 ×3，下限 0.1 s；摄像头上限为 0.5 s。启动时还没有历史间隔，只有摄像头应用固定上限。超过阈值则重置滤波和方差窗口，跳过跨缺口的速度，图表断开。质量工具沿用该判定，记录实际间隔和当时阈值，不随查询区间改判。连续段仅描述已采样帧，不能证明缺口内发生了什么。局部质量和采样缺口每类最多返回 5 段，按跨度排序并另报总数和省略数；缺口中不插值。
- 角度极值事件包含同一 raw/filtered 口径下的真实源秒时间，并列值取区间内首个采样；没有有效角度则事件为 null。报告保留前后段各自局部质量与源时间，沿用图表/视频定位和 JSON 保存；原354列CSV不增加列。

工具包括 get_session_info、get_quality_summary、query_metrics、compare_intervals、seek_to_time、set_chart_view、prepare_report、prepare_export。schema 校验先于执行，所有统计和数值由本地 TypeScript 计算。

证据包含会话版本、参数、来源、区间、口径、有效样本与单位。报告/导出句柄受当前版本约束，失效后须重新准备。
